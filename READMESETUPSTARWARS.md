# SET UP STAR WARS TEST


## 🇬🇧 English

## Project Setup and Execution

### Requirements
To run the project, you only need:

- Python 3

The code uses exclusively standard library modules, so no external dependencies are required.

### Installation
Clone the repository and navigate to the project folder:

```bash
git clone <https://github.com/B-u-b-y/Progetto_TLN.git>
cd star_wars_test
```

### Execution

Run the program with:

```bash
python test_test.py
```

### Virtual Environment (Optional)

```bash
python -m venv .venv
.venv\Scripts\activate
python test_test.py
```
